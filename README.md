# Sistema de Precios — Taller Nevada & Amurai

Material para los asistentes del taller **Sistema de Precios**, impartido por
Nevada & Amurai en la Cámara de Comercio de Granada.

**Acceso:** https://joseramonalvarez-gif.github.io/taller-sistema-precios/

## Contenido

- **La presentación completa** del taller (los 6 pasos).
- **Cuatro herramientas interactivas**, también utilizables por separado:
  - Curva de valor (Paso 2)
  - Margen y punto de equilibrio (Paso 3)
  - Escalera de precios (Paso 4)
  - Mapa del proceso de venta (Paso 5)

## Notas de uso

- Se ve mejor en ordenador, con Chrome y a pantalla completa.
- Lo que se escribe en las herramientas **no sale del navegador**: no se envía
  ni se guarda en ningún servidor.
- Funciona **sin conexión**: no depende de ningún servicio externo. Para usarlo
  offline, descarga el ZIP del paquete completo, descomprímelo entero y abre
  `Presentacion/taller_pricing_COMPLETO.html`.
