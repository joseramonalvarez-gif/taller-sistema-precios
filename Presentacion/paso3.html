VENTA / FACTURACIÓNTodo lo que ingresas por vender
PRECIO UNIDADA cuánto vendes cada unidad
COSTE VARIABLELo que cuesta cada unidad (sube y baja con las ventas)
MARGEN CONTRIB. (€)Precio − coste variable: lo que deja cada venta
MARGEN CONTRIB. (%)Ese margen, sobre el precio
COSTES FIJOSLo que pagas vendas o no (tu estructura)
PUNTO EQUILIBRIO (uds)Cuántas ventas para no perder ni ganar
PUNTO EQUILIBRIO (€)Cuánta facturación para no perder ni ganar
